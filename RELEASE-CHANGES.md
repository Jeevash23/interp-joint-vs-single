# Changes from the original projects

This release puts together two separately exported and checked releases, unchanged, in `small-networks/` (Studies 1–3)
and `gpt2/` (Study 4). Their own `RELEASE-CHANGES.md` files list how each differs from the project in which its studies
ran. The SHA-256 of each part's `SHA256SUMS` is recorded in `release-changes.json` under `parts`.

The manuscript's generated numbers and tables in `paper/generated/` are written by `paper/check_numbers.py` from the
two parts' generated files; its LaTeX source is not included.
