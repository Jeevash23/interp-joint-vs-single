# Changes from the original project

This release was exported from the project folder in which the study ran. Files are copied byte for byte except those
listed below. There are five kinds of change:

- **adapted:** code that read the companion study from another folder now reads `reference/joint-vs-single-interchange`;
  the GPT-2 Small checkpoint comes from `MODELS_DIR` (default `models/`); the cloud app builds its image from this
  folder's `pyproject.toml` and `uv.lock`; the GPU lock script takes its lock file from `GPU_LOCK`; and the freeze
  check accepts the changes this file documents.
- **replaced:** the project's `Makefile`, which the freeze lists, is replaced by this release's; the original is kept
  (redacted) as `provenance/Makefile-at-freeze`.
- **reduced:** each `arm-a.npz` of the GPT-2 Small runs keeps only the four arrays `paper/make_numbers.py` reads; the
  originals (1.57 MB each, subspace bases, margins and margin-rule scores) are not shipped.
- **redacted:** records in which personal or machine-specific strings were replaced: absolute paths and other projects'
  folder names by placeholders (`<project>`, `<companion-project>`, `<environment-project>`, `<environment>`,
  `<portfolio>`, `<portfolio-root>`, `<workspace>`, `<research>`, `<sibling-project>`, `<coordination-folder>`,
  `<home>`), cloud object ids by `[redacted]`, local clock times by `[local time]` (times in UTC are kept), and the names of the writing and coding tools in working records by the placeholder `[redacted]` (the assistants used are named in the top-level README.md, under "Use of AI assistants"). Nothing else in these files changed; the counts show how
  many strings of each kind were replaced.
- **not shipped:** files named in a freeze record but left out (listed at the end with their SHA-256).

Saved outputs are archives under `data/saved-outputs/`; `tools/unpack.py` restores them byte for byte and checks each
SHA-256 against `data/PACKED-FILES.json`. Compression is not a change and is not listed below.

To check the freeze records (the study's files, the companion study's inputs, the Amendment 2 record and the prompt
hashes) against this release: `make check-freezes`.
