# AI-05 question, comparator, and gate (29 September 2026)

Question: for a declared two-variable compositional claim, how often do restricted single-variable interchanges accept an independently invalid explanation, and do held-out singles, joint edits, natural executions, or a faithfulness control reject it at matched query cost?

Closest comparator: Méloux et al., *Validating Causal Abstraction Metrics on Simulated Complex Systems*, arXiv:2607.00267v1, sections 2-5 and appendices C-F. It compares over 30 metrics across ten reference systems, includes a Tracr transformer, tests a hidden XOR backup path, and explicitly samples multi-variable interventions and perturbations of unmapped variables. Its causal abstraction error with faithfulness addresses much of the broad question. The paper's Appendix D concerns composition **across abstraction levels**, not specifically whether two variable edits from one recipient commute. Its broad validity claims and thresholds are the authors', not AI-05 findings.

Other primary work: Geiger et al., *Causal Abstraction: A Theoretical Foundation for Mechanistic Interpretability*, JMLR 26 (2025), formalizes interchange and causal scrubbing. Grant et al., arXiv:2511.04638v5, sections 4.2.1 and 5, gives a concrete off-manifold patch that activates a dormant ReLU unit and a counterfactual-latent control. Chen et al., arXiv:2605.12671v1, tests multiple faithful sparse circuits; low overlap is not an invalidity label. Rai et al., arXiv:2605.09129v1, finds dataset-specific circuits and cross-dataset faithfulness failures; its task differs from two-variable composition. The official Tracr repository is Apache-2.0 and archived since 10 April 2025.

Feasibility: local Git could not resolve github.com on 29 September. We do not have a pinned official code commit, compiled Tracr checkpoint, or compatible isolated JAX runtime. Tracr/CAE exact code replication is **not qualified**. One bounded lighter alternative is an equation-level reproduction of Grant et al.'s published 4D ReLU example using the exact printed weights and activations. It is a methodological reconstruction, not an official-code replication. No other substitute will be called a replication.

Decision: **proceed narrowly** with an auditable finite-domain diagnostic comparison and this equation-level reproduction. This is not a novel broad benchmark, a universal certificate, or evidence about unrestricted language models. A standard faithfulness control receives full credit if it rejects the constructed false claims. If instrumentation or positive/negative reference gates fail, close as a feasibility report.
